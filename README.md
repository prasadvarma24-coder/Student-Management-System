# Student-Management-System
A modern, responsive and interactive Student Management Dashboard built using React.js, JavaScript (ES6+) and CSS3. This project provides a clean dark-themed interface to manage student records, monitor academic performance and view dashboard statistics.  

🚀 Project Overview
🚀 Project Overview

The Student Management Dashboard helps administrators manage student information through an attractive and user-friendly interface.

It includes student management features, real-time search, performance statistics and responsive layouts.

✨ Features

Dashboard Overview – Displays student statistics and performance summaries.

Student Management – Add and delete student records.

Search Functionality – Search students by name, email or course.

Performance Analytics – Visual performance bars and average marks.

Dynamic Statistics – Automatically updates total students, active students, courses and average scores.

Responsive Design – Supports desktop, tablet and mobile devices.

Dark Theme – Modern dark UI with gradient colors and interactive elements.
